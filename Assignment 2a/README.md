# Assignment 2a: Forced Alignment Using Montreal Forced Aligner (MFA)

This project aligns speech audio with text transcripts using the Montreal Forced Aligner (MFA). It measures word and phoneme boundaries across native radio news and non-native English learner recordings.

- **Python:** 3.10 (tested with 3.10.22; compatible with 3.10–3.11)
- **Conda / Mamba:** Miniconda or Anaconda

- **Python Packages:** `textgrid`, `praat-parselmouth`, `nltk`, `matplotlib`, `numpy`

## Step 1: Install MFA and Download Models

From the repository root, enter the `Assignment 2a` directory, set up the Conda environment, and download the acoustic models:

```bash
cd "Assignment 2a"
conda create -n mfa -c conda-forge montreal-forced-aligner python=3.10 ffmpeg sox -y
conda activate mfa
mfa model download acoustic english_us_arpa
mfa model download acoustic english_mfa
pip install textgrid praat-parselmouth nltk matplotlib numpy
```

## Step 2: Prepare the Dataset

> **CRITICAL AUDIO REQUIREMENT (NIST SPHERE Conversion):**
> The three Boston University radio news recordings in `wav/` (`F2BJRLP1.wav`, `F2BJRLP2.wav`, and `F2BJRLP3.wav`) are formatted with legacy **NIST SPHERE** container headers (`NIST_1A`). Montreal Forced Aligner, PySoundFile, and standard audio players cannot read NIST SPHERE audio and will fail immediately.
> 
> **These 3 BU audio files MUST be converted to standard 16 kHz 16-bit mono RIFF PCM WAV before running alignment.**

Running the automated preparation script converts the NIST audio, standardizes the ISLE recordings, cleans all transcripts (stripping punctuation and normalizing to uppercase), and writes the aligned audio/transcript pairs into `corpus_normalized/`:

```bash
python scripts/prepare_corpus.py
```

> **Note on `corpus_normalized/`:** The `corpus_normalized/` folder is created by running Step 2. All subsequent steps (MFA alignment in Step 4, Praat inspection, and plotting in Step 5) directly read audio and transcript pairs from `corpus_normalized/`.

## Step 3: Dictionaries

The complete speech corpus contains **145 unique words**. An audit against the baseline CMU dictionary (`english_us_arpa.dict`, 142 unique words) and baseline MFA IPA dictionary (`english_mfa_standard.dict`, 142 unique words) revealed:
- **Present in Baseline (2 words):** `DUKAKIS` and `HENNESSY` already existed in the baseline lexicons.
- **Out-of-Vocabulary / Added (3 words):** Exactly three target vocabulary words were absent: `MAFFY`, `MELNICOVE`, and `WBUR`.

### Phonetic Curation of Missing Items:
1. `MAFFY`: Generated via G2P $\rightarrow$ Arpabet: `M AE1 F IY0`, IPA: `m æ f iː`.
2. `MELNICOVE`: Generated via G2P $\rightarrow$ Arpabet: `M EH1 L N IH0 K OW0 V`, IPA: `m ɛ l n ɪ k oʊ v`.
3. `WBUR`: Transcribed as an initialism spelling out each letter name:
   - **Arpabet:** `D AH1 B AH0 L Y UW0 B IY1 Y UW1 AA1 R`
   - **IPA:** `d ʌ b ə l j uː b iː j uː ɑ ɹ`

### Pre-built Dictionaries Included in `dict/`:

| Dictionary File | Phone Set | Unique Words | Total Entries (Lines) | Description |
| :--- | :--- | :---: | :---: | :--- |
| `dict/english_us_arpa.dict` | Arpabet | 142 | 142 | Baseline CMU dictionary; 3 OOV words omitted. |
| `dict/custom_us_arpa.dict` | Arpabet | 145 | 145 | Curated dictionary with 3 OOV words added. |
| `dict/english_mfa_standard.dict` | IPA | 142 | 222 | Baseline MFA dictionary with multi-pronunciation variants (e.g. 5 for `dukakis`). |
| `dict/custom_mfa_ipa.dict` | IPA | 145 | 221 | Curated dictionary (+3 OOV words, redundant variants of `dukakis` consolidated, yielding $222 - 4 + 3 = 221$ lines). |

No extra G2P download is needed to run the alignments. *(Optional) To rebuild the dictionary files:*
```bash
python scripts/build_dictionary.py
python scripts/build_ipa_dictionaries.py
```

## Results Summary

Performance metrics from `experiments/comparison/alignment_metrics.csv`:

| Exp | Acoustic Model | Phone Set | Dictionary Used | Status | Success Rate | Run Time | Words Aligned |
| :---: | :--- | :--- | :--- | :---: | :---: | :---: | :---: |
| **E1** | `english_us_arpa` | Arpabet | Standard (`english_us_arpa.dict`) | COMPLETED | 6 / 6 (100%) | 27.84 s | 246 |
| **E2** | `english_mfa` | IPA | Standard (`english_mfa_standard.dict`) | COMPLETED | 6 / 6 (100%) | 29.03 s | 246 |
| **E3** | `english_us_arpa` | Arpabet | Custom (`custom_us_arpa.dict`) | COMPLETED | 6 / 6 (100%) | 28.38 s | 246 |
| **E4** | `english_mfa` | IPA | Custom (`custom_mfa_ipa.dict`) | COMPLETED | 6 / 6 (100%) | 34.92 s | 246 |

### Acoustic Model Performance Analysis

- **Execution Runtime:** Baseline E1 finished fastest at **27.84 s**, followed closely by curated E3 at **28.38 s** (+0.54 s). Both Arpabet setups completed substantially faster than their IPA counterparts: E2 took **29.03 s**, while E4 took **34.92 s** (a 23.0% increase over E3).
- **Lexical Coverage:** While E1 had the fastest overall execution time (27.84 s), it relied on the standard dictionary and lacked pronunciations for OOV proper nouns (`MAFFY`, `MELNICOVE`, `WBUR`). Experiment E3 provides 100% lexical coverage across all 246 words with virtually zero runtime penalty (+0.54 s).
- **Boundary Precision:** On the non-native learner corpus (ISLE), E3 achieved an average boundary Mean Absolute Error (MAE) of **20.75 ms** (with **86.2%** of boundaries within 50 ms of acoustic landmarks). Multi-dialect IPA (E4) exhibited higher boundary displacement (MAE **208.48 ms** overall across all recordings due to phone set differences and consonant duration shifts).
- **Conclusion:** **Experiment E3 (`english_us_arpa` with `custom_us_arpa.dict`)** delivers the optimal configuration: complete lexical coverage of regional proper nouns and call letters without the acoustic validation warnings and 23% runtime penalty of the IPA model.

## Troubleshooting

1. **Audio Header Error (`NIST_1A`):**
   - *Problem:* Audio files in `wav/` have NIST SPHERE headers. MFA crashes when reading them.
   - *Fix:* Run `python scripts/prepare_corpus.py` to transcode them to 16 kHz 16-bit mono RIFF WAV files.

2. **Single-Speaker Warning:**
   - *Problem:* MFA warns that jobs are reduced to 1 because all audio is in a single speaker folder.
   - *Fix:* This is expected. You can add `--single_speaker` to the MFA command to split utterances across cores.

3. **Ignored IPA Symbol in E4:**
   - *Problem:* MFA warns that 1 pronunciation was ignored due to an unrecognized phone symbol.
   - *Fix:* Ensure IPA symbols in `dict/custom_mfa_ipa.dict` match the standard phone set of `english_mfa`.

4. **Missing Python Modules:**
   - *Problem:* Running scripts gives `ModuleNotFoundError: No module named 'textgrid'`.
   - *Fix:* Install requirements with `pip install textgrid praat-parselmouth nltk matplotlib numpy`.
